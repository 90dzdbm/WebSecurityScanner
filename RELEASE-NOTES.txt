Web 安全测试工具 v1.1.0 — Windows 64 位发行版
================================================

一、目录结构
------------
WebSecurityScanner-v1.1.0-win64/
├── single-file/
│   └── WebSecurityScanner.exe        # 单文件版（约 13MB）
├── directory-build/
│   └── WebSecurityScanner/           # 目录版（推荐，约 27MB）
│       ├── WebSecurityScanner.exe    # ← 双击这个运行
│       └── _internal/                # 运行时依赖，请勿删除或单独移动 exe
└── README.md                         # 完整使用说明

二、如何选择版本
----------------
- 优先使用【目录版】：把整个 directory-build/WebSecurityScanner 文件夹拷到目标机器，
  双击其中的 WebSecurityScanner.exe 即可运行，启动快、兼容性最好。
  注意：exe 必须和同级的 _internal 文件夹放在一起，不能只复制 exe。

- 【单文件版】只有一个 exe，便于分发，但首次启动会把自身解压到系统临时目录（%TEMP%），
  需要满足两个条件：
    1) 当前用户对 %TEMP% 有读写权限、且磁盘空间充足；
    2) 安全软件未拦截临时目录写入。
  若启动时出现 “Failed to extract ...” 或弹出标题为 Error 的窗口，说明本机临时目录受限，
  请改用目录版，或用管理员权限运行、或更换一台常规 Windows 机器。

三、运行环境
------------
- 64 位 Windows 10 / 11；
- 已内置 Python 运行时与全部依赖，目标机器无需安装 Python；
- 首次运行若被 Windows SmartScreen 拦截，选择“更多信息 → 仍要运行”即可。

四、使用简述
------------
1. 双击运行，界面标题为“Web 安全测试工具”。
2. 填写目标 URL（可省略协议，自动补 http://），选择扫描强度
   （低 / 中 / 高 / 自定义）。
3. 可选：勾选“持续扫描”（循环执行直到停止）、勾选“超强力扫描”
   （按数量打开相同参数的子扫描窗口，可一键打开 / 关闭，子窗口自动最小化避免遮挡主窗口）、
   勾选“有害化攻击模式”（追加时间盲注、命令注入回显等激进探针）。
4. 点击“开始扫描”，在授权确认对话框勾选“我确认拥有该目标的测试授权”后开始。
5. 扫描结束在报告预览窗口查看结果，可“保存报告”为 .txt。

五、v1.1.0 更新内容
-------------------
- 新增“有害化攻击模式”：表单检测追加扩展 SQLi、时间盲注（SLEEP/WAITFOR）、
  命令注入回显、扩展 XSS 变体；报告与日志单独标注检测模式。
- 超强力扫描的子窗口开始扫描后自动最小化到任务栏，避免遮挡主窗口；
  扫描结束自动恢复显示报告。
- 版本号更新至 1.1.0。
